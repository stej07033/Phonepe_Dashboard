# 📊 PhonePe Transaction Analysis Dashboard (Excel)

A professional Excel dashboard built using **Pivot Tables, Pivot Charts, Slicers, and KPI Cards** to analyze PhonePe transaction data across different states, transaction types, and years. This project demonstrates advanced Excel dashboard development and business data analysis skills.

---

# 📌 Project Overview

The PhonePe Transaction Dashboard provides an interactive visualization of digital payment trends using Microsoft Excel.

The dashboard enables users to explore transaction volume, transaction value, state-wise performance, quarterly growth, and payment categories through dynamic Pivot Tables and Charts.

It is designed for recruiters, business analysts, and data analysts to showcase Excel analytics skills.

---

# 🎯 Objectives

- Analyze PhonePe transaction data.
- Identify top-performing states.
- Compare transaction types.
- Monitor yearly and quarterly trends.
- Create an interactive dashboard using Excel.
- Generate business insights through Pivot Tables.
